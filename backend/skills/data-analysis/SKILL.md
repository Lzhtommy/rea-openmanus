# Data analysis

- Inspect the data first (shape, columns, dtypes, nulls) with pandas before drawing conclusions.
- Save analysis code in a .py file and run it; save charts as PNG files with matplotlib (use a CJK-capable font such as "Noto Sans CJK SC" for Chinese labels).
- Report numbers computed by code, never estimated — this includes percentages and growth rates quoted in reports.
- Include the charts as attachments in the final message.
